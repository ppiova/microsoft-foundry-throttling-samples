# Microsoft Open Source Code of Conduct

This project has adopted the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).

Resources:

- [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/)
- [Microsoft Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/)
- Contact [opencode@microsoft.com](mailto:opencode@microsoft.com) with questions or concerns about the code of conduct itself

This repository is an independent community project rather than a Microsoft owned repository. Report
conduct concerns about this project to the maintainer through
[GitHub Security Advisories](https://github.com/ppiova/microsoft-foundry-throttling-samples/security/advisories/new),
which keeps the report private.
